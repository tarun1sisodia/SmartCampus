# Design

## Theme & Aesthetics
- **Colors**: Use the primary color scheme of SmartCampus. Clean whites, soft greys, and a strong accent color (e.g., deep blue or vibrant green) for interactive elements.
- **Typography**: Modern, readable fonts (e.g., Inter, Roboto, or Outfit).
- **QR Scanner UI**: 
  - Provide a clear, centered scanning area.
  - Show a semi-transparent overlay around the scanning box to focus the user's attention.
  - Implement smooth micro-animations for success or failure states.
  - Must feel premium, avoiding basic or generic layouts.
