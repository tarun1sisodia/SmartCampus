# Documentation Rule

Before planning or executing any task in this workspace, you MUST ensure you have the latest context by reading the following files located at the root of the project:
1. `PRD.md`
2. `Architecture.md`
3. `Rules.md`
4. `Phases.md`
5. `Design.md`
6. `Memory.md`

You MUST constantly update `Memory.md` as you make progress on tasks so that the context is preserved across sessions.
Do not ignore these files under any circumstances.
